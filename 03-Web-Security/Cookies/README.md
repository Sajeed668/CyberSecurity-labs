# Cookies

## Objective

Understand browser cookies and their security attributes.

## Concepts

- `Set-Cookie`
- `Cookie`
- `Secure`
- `HttpOnly`
- `SameSite`
- `Domain`
- `Path`
- `Expires` / `Max-Age`

## Security Checks

During an authorized assessment, inspect whether authentication cookies use appropriate security attributes and whether logout and expiration behave correctly.

## Key Idea

Cookie → data stored/transmitted by the browser.

Session → application mechanism used to maintain user state.
