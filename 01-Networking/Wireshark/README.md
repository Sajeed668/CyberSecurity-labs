# Wireshark

## Objective

Learn packet capture and basic network traffic analysis in controlled lab environments.

## Concepts

- Packet capture
- Ethernet frames
- IP packets
- TCP and UDP
- DNS traffic
- TCP streams
- Packet filtering

## Practice

Wireshark is used to inspect traffic generated by systems and applications that I am authorized to analyze.

## VAPT Relevance

Traffic analysis can help understand protocols, application behavior, and network communication during authorized assessments.

## Disclaimer

Capture and inspect only traffic you own or have explicit authorization to analyze.
