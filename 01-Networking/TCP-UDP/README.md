# TCP and UDP

## Objective

Understand the differences between TCP and UDP and how ports are used for network communication.

## Concepts

- TCP connection-oriented communication
- UDP connectionless communication
- Source and destination ports
- TCP handshake
- Reliability and ordering

## Linux Practice

```bash
ss -tuln
ss -tulpn
```

## VAPT Relevance

Understanding TCP/UDP and listening ports is fundamental to network enumeration and authorized security testing.
