# ARP — Address Resolution Protocol

## Objective

Understand how devices map IPv4 addresses to MAC addresses on a local network.

## Commands Practiced

```bash
ip neigh
ip a
```

## Concepts

- ARP requests and replies
- IP-to-MAC mapping
- Neighbor table
- Local network communication

## VAPT Relevance

ARP and neighbor information can help understand hosts on an authorized local network.

## Disclaimer

Perform network discovery only on networks you own or are explicitly authorized to test.
