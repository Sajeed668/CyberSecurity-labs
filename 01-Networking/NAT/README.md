# NAT — Network Address Translation

## Objective

Understand how NAT translates private network addresses for communication outside the local network.

## Concepts

- Private and public IP addresses
- Source address translation
- Port Address Translation (PAT)
- Default gateway

## Linux Practice

```bash
ip a
ip route
```

## VAPT Relevance

Understanding NAT is important when analyzing network boundaries and traffic paths during authorized assessments.
