# Routing

## Objective

Understand how Linux uses routing tables to decide where network traffic should be sent.

## Commands Practiced

```bash
ip route
```

## Concepts

- Routing table
- Default route
- Default gateway
- Destination network
- Next hop

## Troubleshooting Flow

Interface → IP address → Routing table → Default gateway → DNS → Internet

## VAPT Relevance

Routing knowledge helps understand network paths and boundaries during authorized assessments.
