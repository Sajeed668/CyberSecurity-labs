# Linux Processes

## Objective

Understand Linux processes, parent-child relationships, process states and basic process enumeration.

## Commands Practiced

```bash
ps aux
pstree
pgrep <process>
top
ss -tulpn
```

## Concepts

- PID and PPID
- Parent and child processes
- Foreground and background processes
- Process states
- `/proc/<PID>/`
- Signals and `kill`

## VAPT Relevance

Process enumeration helps identify running applications, services and security-relevant processes during authorized assessments.
