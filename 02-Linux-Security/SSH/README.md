# SSH

## Objective

Understand SSH as a secure remote administration protocol and learn basic service inspection.

## Concepts

- SSH client and server
- Authentication
- Port 22
- SSH service management
- Secure remote access

## Linux Service Commands

```bash
systemctl status ssh
systemctl start ssh
systemctl restart ssh
```

## VAPT Relevance

SSH is commonly encountered during authorized network enumeration and should be assessed for secure configuration and authentication controls.
